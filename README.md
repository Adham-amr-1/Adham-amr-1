### System Architecture

```text
        Camera / Radar / Sensors
                  │
                  ▼
        ┌─────────────────────┐
        │   Raspberry Pi 5    │

              Custom UART

                   ▼
        ┌─────────────────────┐
        │       ESP32         │
        │ PID + Motor Control │
        └──────────┬──────────┘
                   │
                   ▼
              BLDC Motor
```
